My Project Portfolio

A collection of projects I’ve built while learning and experimenting with cybersecurity, software development, and mobile apps. This repository includes network defense labs, mobile applications, and practical tools focused on solving real-world problems.


## Cybersecurity & Network Defense

*   **[SOC Detection, SIEM & Incident Response Lab](./SOC-Detection-SIEM-Incident-Response-Lab)**
    Built an isolated three-tier virtual SOC environment to simulate adversary tactics, capture endpoint telemetry, and triage security incidents. Deployed Wazuh SIEM integrated with Sysmon and Windows EventChannel to detect MITRE ATT&CK techniques, correlated brute-force authentication and persistence attacks, and engineered a custom Python automation tool for rapid alert parsing and IOC extraction.

*   **[Network Detection and IDS Lab](./Network-Detection-IDS-Lab)** 
    Built an isolated virtual network to simulate, capture, and analyze cyber attacks. Engineered a headless Linux architecture, deployed Suricata for intrusion detection, and performed forensic protocol analysis using `tcpdump`.
